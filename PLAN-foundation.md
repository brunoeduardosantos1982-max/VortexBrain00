## Goal

Turn this empty repo into a runnable Vite + React + TypeScript (strict) app with linting, unit tests, and GitHub Actions CI, so that every later plan can be verified with `npm run lint && npm run typecheck && npm test && npm run build`.

## Fixed decisions (do not deviate or ask)

- Package manager: **npm** (commit `package-lock.json`).
- Node: **22** (set in CI; add `"engines": { "node": ">=20" }`).
- React **19**, Vite (latest stable), TypeScript strict.
- Tests: **Vitest** + `@testing-library/react` + `jsdom`.
- Lint: ESLint **flat config** (`eslint.config.js`) with `typescript-eslint`.
- Formatting: Prettier, default settings, `.prettierrc` containing only `{}`.
- No CSS framework in this plan — a single `src/index.css` with a minimal reset. (Later plans add styles inline in component CSS files.)

   ```json
   {
     "dev": "vite",
     "build": "tsc -b && vite build",
     "preview": "vite preview",
     "lint": "eslint .",
     "typecheck": "tsc -b --noEmit",
     "test": "vitest run",
     "test:watch": "vitest"

   ```
   Dependencies: `react`, `react-dom`. DevDependencies: `vite`, `@vitejs/plugin-react`, `typescript`, `vitest`, `jsdom`, `@testing-library/react`, `@testing-library/jest-dom`, `@types/react`, `@types/react-dom`, `eslint`, `typescript-eslint`, `eslint-plugin-react-hooks`, `prettier`. 2. `tsconfig.json`: `"strict": true`, `"target": "ES2022"`, `"module": "ESNext"`, `"moduleResolution": "bundler"`, `"jsx": "react-jsx"`, `"verbatimModuleSyntax": true`, `"types": ["vitest/globals", "@testing-library/jest-dom"]`, include `src`.
3. `vite.config.ts`: react plugin + Vitest config in the same file:
   ```ts

   ```
4. `src/test/setup.ts`: `import '@testing-library/jest-dom/vitest'`.
5. `index.html` (root, not in public/), `src/main.tsx` (createRoot, StrictMode), `src/App.tsx` rendering an `<h1>VortexBrain</h1>` and an empty `<main aria-label="notes">`.
6. `src/App.test.tsx`: render `<App/>`, assert heading "VortexBrain" is in the document.
7. `eslint.config.js`: flat config combining `typescript-eslint` recommended + `eslint-plugin-react-hooks` recommended; add an `ignores: ['dist', 'coverage']` entry as the FIRST array element.
8. `.gitignore`: `node_modules`, `dist`, `coverage`, `*.local`, `.DS_Store`.
9. `.github/workflows/ci.yml`: on `push` + `pull_request`; `actions/checkout@v4`, `actions/setup-node@v4` with `node-version: 22` and `cache: npm`; then `npm ci`, `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`.

## Edge cases a weaker model will miss

- **Do not run the interactive Vite scaffolder** in a non-empty repo / non-TTY shell — it prompts "ignore files and continue?" and hangs forever. Hand-write the files.
- `verbatimModuleSyntax: true` forces `import type { ... }` for type-only imports; test files importing `Mock` or component prop types will fail typecheck unless `type` is used.
- Vitest `globals: true` is not enough for TypeScript — you must also add `"types": ["vitest/globals"]` in tsconfig or `describe/it/expect` are type errors.
- `@testing-library/jest-dom` needs the `/vitest` entrypoint in setup, and its types in tsconfig `types`, otherwise `toBeInTheDocument()` is an "unknown property" type error.
- In ESLint flat config, a global `ignores` only works as a **standalone object entry**; putting `ignores` alongside other keys scopes it to that config object only, and `eslint .` will then lint `dist/` and fail on generated code.
- `tsc -b` with `verbatimModuleSyntax` requires `tsconfig.node.json` (for `vite.config.ts`) referenced from the root tsconfig via `references`, or `vite.config.ts` fails typecheck because it's outside `include: ["src"]`.
- CI `cache: npm` fails if `package-lock.json` isn't committed — commit it.

## Acceptance criteria

Run each; all must succeed with exit code 0:

1. `npm ci`
2. `npm run lint` — no errors, and it does NOT lint `dist/`.
3. `npm run typecheck`
4. `npm test` — 1 test passes.
5. `npm run build` — produces `dist/index.html`.
6. `npm run preview` then `curl -s http://localhost:4173 | grep VortexBrain` — page serves.
7. Push branch: the GitHub Actions run on this branch is green.
